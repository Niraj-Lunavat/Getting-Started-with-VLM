# Six-week learning roadmap

1. **Week 1:** VLM architecture, tokens, visual encoders, image preprocessing.
2. **Week 2:** BLIP captioning and VQA, evaluate outputs against labeled images.
3. **Week 3:** SmolVLM instruction prompting, image resolution and memory trade-offs.
4. **Week 4:** Qwen-VL for documents, OCR, charts, and failure analysis.
5. **Week 5:** Quantization concepts, edge deployment, Jetson environment validation.
6. **Week 6:** Reproducible benchmarking, quality evaluation, project showcase.

Deliverables: reproducible scripts, test images with permission, measured results, and a written limitations section.
